# 03 · 信息架构与交互规格

> 原则：**5 个主入口**（概览/资产/规划/交付/自动化）+ 设置工具区；每页只回答一个问题；能力不砍，入口收拢。
> **平台化修订：** Agent 是平台一等公民，有独立工作台/工具目录/审批队列；入口结构、前后端映射以 `07-平台化前端与前后端映射.md` 为准。
> 本文件保留页面级交互细节；`07` 负责“页面 → API → 命令 → 工具”的对应关系；加载顺序/骨架/预取见 `08 §2`。

## 1. 全局框架

### 1.1 布局

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：Workspace · 搜索(⌘K) · 通知 · Agent 状态 · 账户/设置    │
├──────────┬───────────────────────────────────────────────────┤
│ 侧栏     │ 页面内容                                           │
│ 概览     │                                                   │
│ 资产     │                                                   │
│ 规划     │                                                   │
│ 交付     │                                                   │
│ 自动化   │                                                   │
└──────────┴───────────────────────────────────────────────────┘
                                     右侧：全局 Agent 抽屉（⌘J）
```

- 侧栏固定 5 项，不出现二级导航；页面内用标签/分段控制。
- **设置不在侧栏**，放右上角账户/齿轮菜单：工作区/安全/数据/连接/外观/审计/关于。
- 顶栏全局搜索打开**命令面板**：跳页面、找资产、找政策、切主题/语言、锁定。
- Agent 按钮打开**全局抽屉**（右侧 420px，可拖宽）；长任务跳 `/automation/runs/:id`。
- 窗口最小 900×600；窄于 1100px 时侧栏收成图标+悬浮标签；Web 端 1280 以上优先三栏。

### 1.2 全局状态

| 状态 | 表现 | 退出方式 |
|---|---|---|
| 未配置保险库 | 顶栏提示“尚未设置主密码”，概览引导 | 设置主密码 |
| 锁定 | 内容区遮罩 + 解锁面板；导航仍可见但不可操作 | 密码 / 恢复码 |
| 离线 | 顶栏“离线”标记；本地功能可用，外部连接禁用 | 网络恢复自动消失 |
| 演示模式 | 顶栏“演示数据”水印；禁止导出真实文件 | 仅演示站 |
| Agent 运行中 | 顶栏状态 + 对象页进度条 | 完成/取消 |
| 等待审批 | 顶栏徽标 + 审批队列 | 批准/拒绝 |

### 1.3 全局交互规范

- **错误**：就地说明 + 可复制错误码；不弹裸 `alert`。严重错误进 toast，表单错误留在字段下。
- **空态**：一句解释 + 一个主操作 + 一个次操作；不写“暂无数据”了事。
- **加载**：骨架屏 > 转圈；超过 300ms 才显示。
- **确认**：删除资产/清空日志/替换导入必须二次确认，confirm 文案含数量与后果。
- **快捷键**：`⌘K` 命令面板、`⌘J` 助手、`Esc` 关闭浮层、`Enter` 确认、`↑↓` 选择。
- **焦点**：浮层打开时焦点进入并循环；关闭后回到触发元素。
- **动效**：只做 120–200ms 的进入/状态过渡；`prefers-reduced-motion` 时归零。
- **文案**：动作按钮用动词（“导出报告”），不用“确定”；错误说“怎么修”。
- **Agent 动作**：写操作必须显示“等待批准”，不得先执行后提示；批准前展示 diff 与影响条数。
- **按钮边界**：每个按钮对应一个命令；无命令的动作不允许出现在界面。

## 2. 概览 Overview

**要回答的问题：** 平台现在什么状态、我该做什么、有哪些待批准？

### 2.1 区块

1. **下一步清单**（最高优先）：按四维就绪项生成可点击待办。
   - 未登记资产 → “去盘点”
   - 资产缺处置 → “为 N 项资产留下决定”
   - 处置为继承但缺继承人 → “指定继承人”
   - 缺账号标识 → “补充账号标识”
   - 触发未配置 → “配置到期触发”
   - 有通道但从未测试 → “发送测试通知”
2. **完成度**：一个环（总量）+ 一条四维分段条（处置/继承人/标识/触发），点击分段跳到对应修复处。
3. **风险卡**：政策未核实 Top 3、备份过期、应用未运行提醒、连接失败、锁定状态。
4. **最近活动**：审计事件流（最近 10 条，可展开）。
5. **Agent 运行与审批**：运行中的 Run（进度/取消）、待批准写操作（数量/diff 入口）、最近失败。
6. **快捷操作**：新增资产 / 发现向导 / 导出报告 / 运行演练 / 交给 Agent。

### 2.2 状态

- **首次运行**：欢迎 + 3 步引导（设置主密码 → 盘点 → 导出），不遮挡主按钮。
- **部分完成**：待办优先，统计其次。
- **全部完成**：显示“可交付”状态 + 下次复核日期 + 演练入口。
- **锁定**：显示锁定面板，不渲染统计。
- **等待审批**：审批卡置顶，显示影响范围与期限。

### 2.3 验收

- 每个待办都能一键跳到修复位置；
- 完成度口径与报告一致；
- 1000 条资产下概览 < 300ms；
- 首屏不出现“本地优先/桌面工具”类口号；
- 待审批数量与 Automation 队列一致；
- Agent 运行状态可取消、可跳 Run 详情。

## 3. 资产 Assets

**要回答的问题：** 我有哪些账号、每项怎么处置？

### 3.1 列表

- 顶部：搜索（防抖 200ms）、分类筛选（财产/人格/混合）、处置筛选、平台筛选、排序（最近/估值）。
- 主操作：`新增资产`、`发现向导`、`导入`、`导出`。
- 列表：表格（桌面宽屏）/ 卡片（窄屏）；列：平台、账号标识（默认打码）、类别、估值、处置、继承人、状态。
- 行内：编辑、删除；点击行进入详情。
- 批量：仅支持“归档/导出”，不做批量改处置（避免误操作）。

### 3.2 详情 `/assets/:id`

- 头部：平台图标、名称、类别、状态、估值、最近更新。
- 区块：
  1. 账号与凭据（凭据默认隐藏；锁定态显示“需解锁”，不显示空串）
  2. 处置决定（六种：继承/变卖/纪念/授权访问/删除/捐赠；继承时继承人与联系方式必填）
  3. 备注与标签
  4. 平台政策摘要（材料/流程/难度/时长/官方链接/是否已核实）
  5. 相关交付物（报告中的位置、清单中的步骤）
- 操作：保存、删除、复制账号标识、打开官方链接。

### 3.3 编辑器

- 抽屉式（右侧 560px），不跳页；保存后回列表并高亮新行。
- 字段校验即时；错误在字段下。
- 凭据字段：输入后立即加密；不显示明文回显；锁定态禁用。

### 3.4 发现向导

- 入口：列表顶部 / 概览待办。
- 三步：十项自检问卷 → 推荐平台（按分类）→ 批量创建（可取消单个）。
- 可跳过；不强制完成。
- 结果：创建为“待完善”资产，进入待办清单。

### 3.5 状态

空列表、筛选无结果、加载骨架、锁定、错误（含重试）、部分导入成功（错误行报告）。

### 3.6 验收

- 新增资产 ≤ 3 分钟（首次用户路径测试）；
- 1000 条列表首屏 < 200ms；
- 搜索不卡顿（防抖 + 虚拟列表）；
- 凭据从不以明文出现在列表/日志；
- 删除有确认与审计。

## 4. 规划 Plan

**要回答的问题：** 我失联后谁来接、怎么接？

### 4.1 标签

`持有人` / `继承人` / `触发`

#### 持有人

- 姓名、出生日期、联系方式、常用邮箱。
- 紧急联系人：姓名、关系、电话、邮箱。
- 主继承人摘要（跳“继承人”标签）。

#### 继承人

- 列表：姓名、关系、电话、邮箱、份额说明、执行人标记。
- 新增/编辑/删除；执行人唯一（切换时提示原执行人将被取消）。
- 校验：至少一位继承人；执行人必须有邮箱或电话；重复姓名提示。

#### 触发（DMS）

- 总开关、间隔天数、三级收件人（本人/紧急联系人/执行人）、通道（SMTP/本地发件箱）。
- 状态时间线：正常 → 一级 → 二级 → 三级；当前阶段、超期天数。
- 操作：`我还安好`、`暂停到某日`、`立即测试`、`查看发件箱`。
- 可靠性提示：应用未运行/无 SMTP 时显著警告，不假装已通知。

### 4.2 状态

未配置、已配置未测试、测试失败、暂停中、已触发（只读展示）、锁定。

### 4.3 验收

- 执行人唯一性有测试；
- 签到后阶段复位；
- 暂停到期自动恢复；
- 无 SMTP 时明确显示“仅本地发件箱”；
- 触发配置变更写审计。

## 5. 交付 Deliver

**要回答的问题：** 家人拿到什么、能不能照着做？

### 5.1 标签

`报告` / `家人清单` / `法律文书` / `工具包` / `质量审核` / `演练`

#### 报告

- 预览（HTML 渲染，分页感）；语言切换中/英。
- 操作：刷新、导出 HTML、导出 PDF、打印、复制路径。
- 显示：生成时间、模板版本、是否含未解密字段（含则禁止导出）、文件哈希。

#### 家人清单

- 按平台聚合；筛选分类/难度；每平台：材料、流程、时长、难度、官方链接、继承人。
- 导出 HTML/打印；空态引导先完成资产处置。

#### 法律文书

- 六类模板：遗嘱、授权委托、数字资产清单、告知函、继承声明、保管说明。
- 筛选、预览、下载、免责声明（不构成法律意见）。

#### 工具包

- 内容清单：报告、清单、FAQ、法律文书、恢复包、保管提示。
- 导出 ZIP；显示大小、文件数、生成时间、哈希。
- 可选包含/排除单项（恢复包默认不含，需显式勾选）。

#### 质量审核

- 五个场景卡片：政策 / 法律 / 家人说明 / 资产分类 / 继承人可读性。
- 队列：待审、AI 已审、已批准、已驳回、需修改；进度条。
- 条目详情：原文、AI 建议、证据、人工结论、理由（严格场景必填）。
- AI 未配置时只显示人工队列，不显示“AI 审核中”。

#### 演练

- 开始演练 → 按家人视角回答 6-8 个问题（能否找到文件、能否看懂步骤、卡在哪）。
- 结果：平台数、卡点数、建议、耗时；保存历史。
- 对比上次演练。

### 5.2 状态

未完成规划（禁止导出并说明缺什么）、含占位符（禁止）、生成中、生成失败、已生成、已导出。

### 5.3 验收

- 任一交付物在未解锁时拒绝生成；
- 导出文件可脱离应用打开；
- 报告与清单字段一致（同一来源）；
- 导出记录含哈希与模板版本；
- 家人清单每一步都能被执行（演练验证）。

## 6. 设置（全局工具区）

**要回答的问题：** 这个平台怎么配、数据怎么保护、能力接哪里？
**入口：** 右上角账户/齿轮菜单，路由 `/settings/*`；**不在侧栏**。

### 6.1 标签

`工作区` / `安全` / `数据` / `连接` / `外观` / `审计` / `关于`

#### 工作区

- 名称、创建时间、版本、部署形态（本地/自托管）。
- 数据导出、工作区重置（二次确认 + 备份）。
- 本期单工作区；多租户/成员不显示入口。

#### 安全

- 主密码：设置/修改（旧密码 + 新密码 + 确认）。
- 立即锁定、闲置自动锁定（10 分钟，可配 5/10/30）。
- 整库加密：状态、开启/关闭（带快照说明）。
- 恢复码：生成、查看一次、重新生成（使旧码失效）。
- 恢复包：生成 3-of-5 份额、打印、状态。
- 安全提示：本地加密挡不住以你身份运行的恶意软件。

#### 数据

- 备份：立即备份、自动备份状态、最近备份时间、保留 7 天。
- 检查点：创建、恢复、删除；恢复前自动 `pre-restore`。
- 导入/导出：备份 JSON、平台补丁；merge/replace；认证提示。
- 保管提示：凭据放在哪里（custody hints）。
- 诊断：导出诊断包（版本、schema、最近错误、审计摘要；不含凭据）。

#### 连接

- 卡片：LLM、政策数据、SMTP、IMAP、心跳。
- 每张：启用开关、配置字段、密钥（已保存则显示“已保存”）、测试连接、最近检查时间、状态、最近错误。
- LLM：端点、模型、Key、超时、流式开关、预估成本提示。
- 政策：端点、Key、自动拉取频率、上次同步、候选数。
- SMTP：主机、端口、发件人、用户名、密码、TLS 模式、测试收件人。
- IMAP：主机、端口、用户名、密码、签到地址规则。
- 心跳：端点、令牌、间隔、自托管说明。

#### 外观

- 语言（中/英）、主题（亮/暗/跟随系统）、减少动效、字号（标准/大）。

#### 审计

- 审计事件列表：时间、类型、主体、对象、结果。
- 校验哈希链、导出审计包、按类型/时间筛选。
- Agent 运行与审批记录可跳转。

#### 关于

- 版本、schema 版本、许可、第三方依赖清单、检查更新、打开官网、诊断包。

### 6.2 状态

未配置、已配置未测试、测试中、成功、失败、锁定（密钥字段不可编辑）。

### 6.3 验收

- 旧 4 张配置表迁移后功能不变；
- 密钥字段永不明文回显；
- 测试连接失败不阻断保存，但状态为 error；
- 所有连接变更写审计；
- 诊断包不含凭据/姓名/联系方式；
- 设置不出现在侧栏；旧设置卡片不再散落在个人资料页。

## 7. 自动化 Automation（摘要）

> 完整规格见 `07 §2/§3/§6`；这里只定义页面级验收。

- 标签：`Agent` / `工具` / `运行` / `审批` / `计划任务`。
- Agent：内置/自定义 Agent 列表，模型、预算、可用工具、启停。
- 工具：Tool Registry 目录；权限、审批策略、可用范围、最近调用。
- 运行：Run 列表与详情；步骤时间线、工具调用、耗时、token/成本、失败、取消。
- 审批：待批准写操作；diff、影响条数、批准/拒绝/修改、理由。
- 计划任务：政策同步、完整度检查、备份提醒；可暂停/立即运行。
- 验收：
  - 每个 Run 可追溯到工具调用与审计；
  - 所有写操作必须经审批，禁止自动批准；
  - 取消 1 轮内生效；
  - 工具目录与 `contracts/tools.json` 一致；
  - `key`/`network`/`desktop` 工具不在 Agent 可调用列表。

## 8. Agent 工作台与全局抽屉

### 8.1 触发与布局

- 顶栏按钮 / `⌘J` / 任意页面“交给 Agent”。
- 右侧抽屉 420px，可拖到 720px；不遮挡主操作（窄屏时全屏覆盖）。
- 顶部：模式（问答 / Agent）、模型、连接状态、清空历史、打开工作台。
- 中部：消息流；Agent 模式显示步骤时间线（轮次、工具、审批、结果摘要）。
- 底部：输入框、发送、取消、payload 预览、预计成本。
- 长任务/多步任务：自动跳 `/automation/runs/:id`；抽屉保留摘要与深链。

### 8.2 状态

未配置（引导去设置）、锁定（禁止发起）、流式中（逐字）、等待审批（显示 diff 入口）、失败（重试/回退非流式）、取消中、超预算。

### 8.3 边界

- 出境字段预览与实际请求一致；
- 不发送凭据、账号、姓名、联系方式、金额；
- 锁定态 fail-fast；
- 写工具不得自动执行；必须进审批队列；
- 历史本地保存，可清除；默认保留 90 天。

### 8.4 验收

- 任意页面可开；
- 流式失败自动回退；
- 取消 1 轮内生效；
- payload 预览可折叠、可复制；
- 无连接时明确“未配置”，不假装可用；
- 抽屉里的“等待批准”与 Automation 审批队列状态一致；
- 运行结束后对象页自动刷新（SSE），无需手动重载。

## 9. 命令面板与 onboarding

### 9.1 命令面板（⌘K）

- 输入即过滤；分组：导航 / 资产 / 政策 / Agent / 操作（主题、语言、锁定、备份）。
- ↑↓ 选择、Enter 执行、Esc 关闭；空结果给“没有匹配”与建议。
- 不超过 12 条可见，滚动；页脚显示快捷键提示。

### 9.2 首次引导

## 10. 可访问性与性能（页面级）

| 项 | 要求 |
|---|---|
| 键盘 | 所有操作可键盘完成；焦点顺序合理；浮层焦点陷阱 |
| 读屏 | 地标（header/nav/main）、表格表头、表单 label、错误 `aria-live` |
| 对比度 | 正文/按钮 AA；不只靠颜色表达状态 |
| 动效 | 尊重 `prefers-reduced-motion` |
| 加载 | 路由懒加载；骨架屏；列表虚拟化（>200 条）；启动顺序/预取/长任务见 `08 §2` |
| 搜索 | 防抖 200ms；结果高亮；无结果可清空 |
| 错误 | 错误码可复制；重试按钮；不丢用户输入 |
| Agent | Run 时间线可读屏；审批按钮有明确 label；等待状态不只靠颜色 |
