## 使用方式

1. **任何实现开始前**，先在 `01` 找到模块 ID，在 `02` 读该模块规格，在 `04` 找接口契约；前端实现先读 `07`。
2. **任何新需求**先登记到 `06` 的缺口台账，再决定进哪个里程碑；不允许“先写后补计划”。
3. **模块完成**必须满足 `02` 的通用 DoD，并更新 `06` 的状态看板。
4. 本计划是**执行文档**，不是提案；改动需走 `06` 的变更控制。
