# 资产录入真实用户验收（2026-11-22）

## 结论

能填过，主链路可用。原先拦住真实用户的两处硬问题已修复：常见人民币写法不再被后端当成“非数字”，列表和详情也不再显示裸数字。五个身份、十五种类型都已通过真实单条表单提交成功。

剩下的问题集中在深度字段和连续录入，不是阻断性 bug：没有按类型筛选、没有“保存并继续”、关闭表单会丢草稿、单条表单只有五个字段。

## 测试方法

- 隔离实例：`/tmp/dg-ux-test.db`，API `127.0.0.1:8787`，写令牌 `test-token`，未写入真实库 `data/digilegacy.db`。
- 真实 Chromium，桌面 1920×993；移动端用 CDP 设为 390×844。
- 五位模拟用户：大三学生、自由插画师、中年家庭、个体商户、退休老人。
- 16 条在用资产覆盖 15 个 `AssetKind`；另用单条表单把 15 类各提交一次（名称前缀 `UI全类-`），验证后归档。
- 原生 `<select>` 的弹层不会进入截图，分组和选项通过 DOM 读取确认：11 个 `optgroup`、15 个 `option`、无遗漏无重复。

## 修掉的问题

### 1. 估值必须是纯数字

复现：填 `¥3,200`，点“保存资产”，后端返回 `资产估值必须是数字`。`1,200,000`、`50万`、`120万` 同样会被拒。

处理：`normalizeValuation()` 在提交前把 `¥3,200`、`1.2万`、`约 50 万元`、`3200元` 归一化为整数；无法归一化的 `待评估`、`保额50万`、负数不再发请求，表单内直接提示：

> 估值只填数字（元），可用 3200 或 50万；待评估、保额说明请写备注

字段名也从“估值”改成“估值（元）”，placeholder 给出 `3200；50万也可`，不再让用户猜格式。

### 2. 金额显示是裸数字

列表显示 `3200`、`1200000`，详情标题也只有一个数字。现在统一显示为 `¥3,200`、`¥1,200,000`，最多两位小数，空值在列表显示 `—`。

### 3. “平台”标签不适配非账号资产

“平台”对房产、保险、版权、身份证都不合适。列表和表单统一改为“机构/平台”，placeholder 改为 `招商银行 / 不动产登记中心`。

### 4. 搜索说能搜备注，实际搜不到

界面 placeholder 是“搜索资产名称、平台或备注”，但后端 SQL 只匹配名称、账号标识和平台名。实测 `q=学费` 返回 0 条；补上 `a.notes` 的 `LIKE` 条件后返回“招商银行助学金卡”，并加了回归测试。

### 5. 空估值时列表重复显示类型

列表副标题原来写 `asset.value || 类型标签`，空估值时会在名称下再显示一次类型，和“类型”列重复。现在副标题只显示金额或 `—`，移动端隐藏类型列时再补类型标签。

## 已验证通过

- 空名称：表单内提示“先填资产名称”，不发请求，已填内容保留。
- 只填名称：可以保存，类型默认“账户”，机构显示“未分类”。
- 估值空值：可以保存，列表显示 `—`。
- `¥3,200`、`1.2万`、`120万`：通过单条表单提交，分别存为 `3200`、`12000`、`1200000`。
- `待评估`：表单内立即提示，不发请求，内容保留。
- 15 类：单条表单逐类提交成功，API 复核 `kind` 与选择一致。
- 详情页：金额、类型、机构、状态、备注正常；“机构/平台”文案一致。
- 归档/恢复：归档后默认列表隐藏，详情可恢复，提示明确。
- 移动端 390px：表单单列堆叠，字段不截断；列表只保留名称、状态、金额，类型补在副标题。
- 批量添加页：36 条预置建议，按 8 个类别分组，已在库项目不可重复选择。
- 原生下拉：11 组、15 项全部存在；`金融资产 / 不动产与车辆 / 实物与收藏 / 知识产权 / 企业经营 / 数字账号 / 虚拟物品 / 文件、设备与域名 / 订阅与会员 / 身份与权益 / 其他`。

## 仍然缺失

按影响排序：

1. **单条表单只有五个字段**：名称、类型、机构/平台、估值、备注。账号标识、权属份额、受益人、凭证位置、到期日、数量/单位都没有入口。后端表里有 `account_identifier`，但当前契约和 UI 都没有暴露。对数字遗产来说，这是内容深度问题，不是样式问题。
2. **没有“保存并继续”**：连续录 15 类要反复开关表单。批量添加有 36 条预置，但只适合常见项，不能替代自定义连续录入。
3. **关闭会丢草稿**：点 `×` 直接关闭，没有未保存确认；从表单跳“设置”配令牌再回来，原内容也会丢。写令牌报错本身是清楚的，但没有“去设置”的一键入口。
4. **列表没有类型筛选**：只有状态筛选和关键词搜索。15 类资产多起来后，找“所有知识产权”只能靠扫列表。
5. **估值只有数字一个状态**：`待评估`、`保额50万` 只能写备注；没有“估值状态”字段，也无法区分“市价 / 保额 / 评估价”。
6. **没有物理删除**：只有归档。对遗产场景是安全选择，但用户如果想清掉误录，入口不在资产页。
