# 资产分类口径

资产台账回答的是**这个人持有什么、最终交给谁**；平台政策库回答的是**平台在身后要求什么**。两者是不同数据集，不能混在一起。

## 三条边界

- **资产台账**：账户、文件、设备、域名、订阅、金融权益、不动产、车辆、知识产权、企业经营、虚拟物品、会员积分、身份权益与实物。
- **负债台账**（预留，本版未上线）：房贷、信用卡、消费贷、担保、欠税与未结纠纷。负债不是资产，不能计入资产数量或资产总额。
- **访问材料**（预留，本版未上线）：密码库位置、恢复码、2FA 设备、API Key 与密钥持有人说明。它们是接管支撑，不是可出售资产，也不能以明文备注存放。

平台政策库保持独立。政策行只说明平台如何处理继承，不代表用户拥有该账户。

## 入口分组

资产表单按 `kind` 分组，旧值全部保留。

| 分组 | Kind | 典型对象 |
|---|---|---|
| 金融资产 | `financial` | 存款、银行卡、基金、证券、保单、养老金 |
| 不动产与车辆 | `real_estate`、`vehicle` | 房产、土地、车位、商铺、车辆、船舶 |
| 实物与收藏 | `physical` | 珠宝、艺术品、收藏品、保险箱内容 |
| 知识产权 | `intellectual_property` | 著作权、专利、商标、源代码、版税 |
| 企业经营 | `business` | 股权、合伙份额、经营许可、商户号 |
| 数字账号 | `account` | 邮箱、手机号、社交、支付、云账号 |
| 虚拟物品 | `virtual_item` | 游戏库存、皮肤、钱包余额、数字藏品 |
| 文件、设备与域名 | `file`、`device`、`domain` | 文档、硬盘、服务器、域名、网站 |
| 订阅与会员 | `subscription`、`membership` | SaaS、会员、积分、储值 |
| 身份与权益 | `identity` | 证件、学历资格、执照、待遇权益 |
| 其他 | `other` | 以上都不适合的对象 |

## 兼容规则

- 原来的七类（`account`、`file`、`device`、`domain`、`subscription`、`physical`、`other`）标识与含义不变。
- 新类型只做加法，旧数据不需要迁移，schema 仍是 v18。
- 每个 kind 只能属于一个分组；Web 测试 `model.test.ts` 会在漏项或重复时失败。
- 新增 kind 时，必须同时更新契约 enum、Rust 白名单、Web 联合类型与分组表。
