# 贡献者公约行为准则

[English](../../CODE_OF_CONDUCT.md) | 简体中文

## 我们的承诺

作为成员、贡献者和维护者，我们承诺让每个人都能在不受到骚扰的情况下参与本项目，不论其年龄、体型、可见或不可见的残障、族裔、性别特征、性别认同与表达、经验水平、教育程度、社会经济状况、国籍、外貌、种族、宗教或性取向。

我们承诺以有助于开放、友好、多元、包容和健康社区的方式行事与互动。

## 我们的标准

有助于营造积极环境的行为包括：

- 对他人表现出同理心和善意
- 尊重不同的意见、观点和经历
- 给出并坦然接受建设性反馈
- 为自己的错误承担责任，向受影响的人道歉，并从中学到东西
- 关注的不仅是个人的利益，还有整个社区的利益

不可接受的行为包括：

- 使用性化语言或图像，以及任何形式的性关注或性挑逗
- 嘲讽、侮辱或贬损性评论，以及人身或政治攻击
- 公开或私下骚扰
- 未经明确许可发布他人的私人信息，例如住址或电子邮箱
- 其他在职业环境中可合理视为不当的行为

## 执行责任

维护者负责澄清和执行这些标准，并对他们认为不当、威胁、冒犯或有害的行为采取适当、公平的纠正措施。

维护者有权也有责任删除、编辑或拒绝不符合本行为准则的评论、提交、代码、wiki 编辑、issue 和其他贡献，并在适当时说明管理决定的理由。

## 适用范围

本行为准则适用于所有社区空间，也适用于个人在公共场合正式代表社区时。

## 执行

如遇辱骂、骚扰或其他不可接受的行为，可通过 `SECURITY.md` 中说明的私下渠道向维护者报告。所有投诉都会被及时、公平地审查和调查。

所有维护者都有义务尊重报告者的隐私和安全。

## 执行指南

1. **纠正**：私下书面警告，说明违规性质以及为什么该行为不当。可能会要求公开道歉。
2. **警告**：警告并说明继续该行为的后果，包括在指定时间内不得与相关人员互动。
3. **临时封禁**：在指定时间内禁止与社区进行任何互动或公开交流。
4. **永久封禁**：永久禁止在社区内进行任何公开互动。
